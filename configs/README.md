# Experiment configurations

Store one YAML/JSON configuration per experiment.

Suggested names:

```text
aptos2019_no_mask.yaml
aptos2019_hard_mask.yaml
aptos2019_fixed_feather.yaml
aptos2019_adaptive_feather.yaml
eyepacs_no_mask.yaml
eyepacs_hard_mask.yaml
eyepacs_fixed_feather.yaml
eyepacs_adaptive_feather.yaml
```

Keep training settings fixed across preprocessing conditions unless the manuscript explicitly states otherwise.
